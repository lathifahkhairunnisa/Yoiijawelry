# Yoii Jewelry — Ready to Deploy

Static website siap upload.

## Cara Deploy
1. Upload semua file & folder ke hosting (cPanel, Netlify, Vercel, GitHub Pages, dll).
2. Pastikan `index.html` jadi halaman utama.
3. Ganti nomor WhatsApp di tombol Custom (cari `wa.me/6281234567890`).

## Struktur
- `index.html` → Homepage
- `tips.html` → Halaman tips styling
- `css/styles.css`
- `js/script.js`
- `assets/products/` → Foto produk asli

Gambar produk menggunakan foto bebas dari Unsplash (bukan dummy).
